# Game Analytics: Unlocking Tennis Data with SportRadar API[cite: 2]

## Project Overview
The Sportradar Event Explorer project aims to develop a comprehensive solution for managing, visualizing, and analyzing sports competition data extracted from the Sportradar API[cite: 2]. The application parses data, stores structured information in a normalized relational database, and provides intuitive insights into tournaments, competition hierarchies, and event details[cite: 2, 3].

## Skills Takeaway[cite: 2]
* **Python Scripting:** Automating workflows and data management[cite: 2].
* **Data Collection:** Working with API integration and parsing datasets[cite: 2, 3].
* **Data Management using SQL:** Designing normalized tables with proper primary and foreign keys[cite: 2, 3, 12].
* **Streamlit Development:** Building interactive web applications and dashboards[cite: 2, 10].

## Project Deliverables
1. **SQL Database:** Populated with structured sports event data from the Sportradar API[cite: 11].
2. **Python Scripts:** Automate data structuring and transform data into a relational format[cite: 11].
3. **Streamlit App (`app.py`):** Interactive web tool for exploring, filtering, and visualizing competition and ranking data[cite: 9, 10, 11].
4. **Documentation:** Detailed report on workflow, schema design, queries, and insights.
